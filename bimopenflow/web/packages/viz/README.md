# @bimopenflow/viz

Chart and table rendering components used in two places: the BimOpenFlow web
editor panes, and the static dashboards generated by the C# Publishing layer.
Both consume the same code — the editor imports the TypeScript source through
the workspace, the dashboard generator embeds the bundled `dist/viz.iife.js`.
That single shared implementation is the point: a published dashboard looks
identical to the live app, because it *is* the same rendering code.

## Design constraints

- **No UI framework.** Plain TypeScript and DOM/SVG. This keeps the embeddable
  bundle small and dependency-free, and keeps the package usable from any
  future host (React panes, static HTML, anything else).
- **Only dependency:** `@bimopenflow/contracts` (generated types, type-only
  imports — nothing at runtime).
- **Invariant formatting.** Values render the same on every machine; no locale
  surprises between a dashboard generated on a server and the live app.
- **Styling** is injected once per document under the `bof-viz-` class prefix
  and driven by CSS custom properties (`--bof-viz-*`), so a host page can
  re-theme without touching the components.

## Components

All components share one shape:

```ts
const handle = Component.mount(container, data, options?);
handle.update(newData);
handle.destroy();
```

`data` is always a `TableData` (`{ columns: ColumnSchema[], rows: unknown[][] }`)
from `@bimopenflow/contracts`.

- **DataTableView** — HTML table. Numeric columns right-aligned, click a
  header to sort (nulls always last), rows capped (default 1000) with a
  "showing N of M rows" footer.
  Options: `{ maxRows?, sortable? }`
- **BarChart** — hand-rolled SVG. Categories from a text column, values from a
  numeric column (defaults: first of each). Zero baseline, negative bars drawn
  downward in the negative color, value labels, y-axis ticks.
  Options: `{ width?, height?, categoryColumn?, valueColumn? }`
- **LineChart** — hand-rolled SVG. X from a numeric column or the row index;
  one path per numeric series with axis ticks; null values break the line.
  Options: `{ width?, height?, xColumn?, seriesColumns? }`

## Builds

- Workspace siblings import the TypeScript source directly (`main` points at
  `src/index.ts`).
- `npm run bundle` produces `dist/viz.iife.js`, a single self-contained IIFE
  exposing the global `BofViz` — the artifact the C# dashboard generator
  embeds. Not committed; rebuilt by the publishing pipeline.

```html
<script src="viz.iife.js"></script>
<script>
  BofViz.DataTableView.mount(document.getElementById("t"), tableData);
</script>
```

## Testing

```
npm test -w @bimopenflow/viz
```

Vitest with jsdom; no browser or server needed.
